# CTAPill

The one orange call to action on a carousel's final slide: an orange-500 pill, 88px tall, with an ink-900 label.

- Label is ink-900, not white: ink-900 on orange-500 is 5.7:1; white is 3.1:1 and fails at phone size.
- One CTA per carousel. Verb first, 2–4 words: "Save this for later", "Follow for more", "Comment AI".
- Place it inside the last slide's GlassCard, under the body, or alone on canvas.
- Not specified in the brief beyond "accent for CTAs": shape and size are assumptions.
