# SwipeCue

Carousel dots plus a "SWIPE" label with an orange arrow; it appears on the cover only.

- Dots: one per slide. Active dot is a 44px white pill; the rest are 14px dots in on-glass-faint (decorative, not text).
- The orange arrow disc is the cover's only accent: it is a call to act. No other orange on the cover except reflections inside the render.
- Sits 48px under the headline, inside the safe margin.
- Use dots, the label, or both. Never on content slides.
