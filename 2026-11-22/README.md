## What I learned

- A plan only works if every day is concrete: each topic has a slot, a time block and a "done" check.
- Explain-first beats Socratic-first when time is short; attempt-first still matters for practice problems.
- Spaced review (1, 3 and 7 days later) is built into the daily schedule instead of left for the end.
