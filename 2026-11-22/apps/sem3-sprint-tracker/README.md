# Sem 3 Sprint tracker

A 15-day exam sprint for Semester 3 (Mon 23 Nov → Mon 7 Dec 2026): 12 learning days and 3 revision days across six subjects (PS, DAA, BE, AIF, LR, COM).

- **Day plan:** each day as timed blocks: DAA 2 h → PS 2 h → BE or AIF 2 h → LR 1 h → COM 45 min → spaced review 45 min.
- **Built-in tutor:** every topic has *Explain simply*, *Exam answer*, *Quiz me* and *Viva*. Each subject has a full mock viva from its 10-question bank.
- **Progress:** tick topics; the first explanation of each topic is saved so it reopens instantly.

`sem3-sprint.html` is the source of a Claude artifact. The tutor and saved progress only work inside claude.ai. Opened as a plain file in a browser, you still get the plan and ticks (saved in that browser).
